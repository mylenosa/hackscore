Como funciona
Como as notas são calculadas?

Cada avaliador dá uma nota por critério (a soma máxima é 100 pontos). A pontuação final da equipe é a média entre todos os avaliadores que a avaliaram. Exemplo: se uma equipe recebeu 80 de um avaliador e 90 de outro, sua pontuação é 85,0.

Como funciona o desempate?

O sistema nunca termina em empate. Se duas equipes ficarem com a mesma média total, aplica-se uma cascata de critérios, do mais relevante ao último recurso:

  1. Critérios de maior peso — vence quem tiver maior média no critério que vale mais pontos; persistindo, passa-se ao próximo critério, e assim por diante.
  2. Maior nota mínima — vence a equipe que convenceu até o avaliador mais rigoroso (a menor nota recebida por ela é mais alta que a da concorrente).
  3. Consistência — vence a equipe com notas mais parecidas entre os avaliadores (menor desvio), indicando maior consenso da banca.
  4. Ordem de cadastro — último recurso, apenas se as notas forem estatisticamente idênticas em tudo (caso raríssimo).

No painel de resultados do admin, equipes desempatadas recebem a tag desempate com a indicação de qual regra decidiu.

Posso alterar uma nota depois de enviar?

Não. Após a confirmação do envio, as notas ficam travadas — o próprio banco de dados rejeita um segundo envio do mesmo avaliador para a mesma equipe. Isso protege a integridade da competição. Se houve um erro real de digitação, procure a coordenação: o admin pode remover a sua avaliação para que você avalie novamente.

Como funciona a revelação no telão?

O admin projeta a tela de revelação no telão. Para cada categoria, o pódio é revelado com suspense, do 3º lugar ao campeão, e ao final aparece a classificação até o 5º lugar. Apenas a equipe campeã de cada categoria é premiada, conforme o edital.

Minhas notas como avaliador são públicas?

O painel do admin mostra a média por critério de cada equipe e quais avaliadores já concluíram. No telão, apenas a pontuação média final é exibida. As notas individuais por avaliador ficam registradas no sistema para fins de auditoria pela coordenação.
